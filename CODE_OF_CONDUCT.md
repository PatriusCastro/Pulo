# Code of Conduct

Pulo follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and respectful, criticise ideas rather than people, and accept that maintainers have the final say on what gets merged.

To report unacceptable behaviour, use GitHub's [private vulnerability reporting](https://github.com/PatriusCastro/Pulo/security/advisories/new) form or contact the maintainer through their GitHub profile. Reports are kept confidential.
